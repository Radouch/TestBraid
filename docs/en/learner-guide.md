# Learner guide

TestBraid lets you complete **published multimedia self-assessment tests** in your browser. You do not need an author account or login.

## 1. Choose a lesson and test

Open the website's home page. It shows lessons that contain published tests, with a link to each available test. Choose a lesson and select a test.

You can also follow a direct link shared by an author. A draft, withdrawn or nonexistent test cannot be opened as a public test.

The page's interface language (English, Czech or another enabled translation) is separate from the language of the **test content**. Switching interface language does not translate the questions themselves.

## 2. Navigate through the test

The test presents all questions on **one continuous page**. Several may remain open at the same time.

- Use the question overview to jump to a question. On a narrow screen, open the compact overview control.
- Expand or collapse individual questions without losing your current answers.
- The overview marks questions as unanswered, partially paired or answered. These are progress indicators, **not** correctness marks until evaluation.
- Play videos and view images directly inside prompts and answers, using the browser's video controls where available.

## 3. Answer choice questions

A choice question has one of two modes:

- **Choose one answer:** select one radio option.
- **Choose several answers:** tick the appropriate checkboxes.

An answer can itself contain text, an image or a video. Selecting the surrounding answer card also works with a pointer; keyboard users can operate the radio buttons/checkboxes directly.

For multiple-answer questions, the complete set must match the correct set to receive the point. There is no partial credit for selecting only some correct options.

## 4. Answer matching questions

Matching tasks show separate sets of **source** items and **counterpart** items. The items may include text, images and videos.

1. Choose an item from the source side, using its card or **Select**.
2. Choose its matching counterpart from the other side using **Assign**.
3. The completed association appears in **Your pairs** above the remaining available items.
4. To revise an association, use **Unpair**; both items return to the available pools so you can match them again.

On phones the two groups can appear **above and below** one another rather than side by side. Follow the visible source/counterpart headings, not a fixed left/right screen position. Pairing a video or image does not prevent using the native media controls.

Counterparts can appear in a different order when you retry the test. Their order is not a hint about correct pairings.

## 5. Submit and review results

Select the evaluation/submit action when you are ready. Unanswered or partially answered questions are allowed; they are not automatically filled in.

After submission:

- Your responses are locked for that attempt.
- Correct, incorrect and unanswered questions are identified with text and visual indicators.
- Choice feedback identifies correctly selected, incorrectly selected and missed correct options.
- Matching feedback shows which pairings were correct and the **actual correct counterpart** for wrong or missing matches.
- Each fully correct question is worth **one point**; there is no partial credit.

If the author has disabled **overall score visibility** for this test, you still receive question-level feedback but not the aggregate points/score.

## 6. Try again and privacy

Use **Try again** to clear your previous answers and begin a fresh attempt. All questions reopen, and matching counterpart order may change.

TestBraid evaluates your responses **locally in the browser**. It does not create a learner account, record a named result, submit answers for teacher grading or maintain progress history. A page reload may discard the active attempt. If an author needs you to report a score, agree separately how to communicate it.

For authors creating these tests, see [Author guide](author-guide.md).
