# TestBraid

TestBraid is a self-hosted application for creating and completing multimedia self-assessment tests.

## Documentation

The current English documentation is organized by task. A full project overview — including why TestBraid exists, its benefits, differences from other tools and limitations — will be prepared separately.

### Installation and operation

- [Upgrading](docs/en/upgrading.md) — upgrade archives, protecting data and verifying the new version.
- [Configuration](docs/en/configuration.md) — site identity, interface languages, URL paths and upload limits.
- [Security and backups](docs/en/security-and-backups.md) — private storage, account protection, diagnostics, backups and restore.
- [Troubleshooting](docs/en/troubleshooting.md) — common hosting, routing, upload and update problems.
